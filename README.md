# Mini HTML, CSS & JavaScript Projects

A collection of mini web development projects built while learning HTML, CSS, and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Projects

- Counter App
- Loading Animation
- Notify Animation
- Password Generator
- Password Strength Checker
- Horizontal Scroll
- Text to Speech
- To-Do List 
- YouTube UI Clone (not complete)

## How to Run

1. Clone the repository.
2. Open any project folder.
3. Open the `index.html` file in your browser.
